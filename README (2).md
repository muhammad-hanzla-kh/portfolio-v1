# Muhammad Hanzla — Interactive Intro Portfolio

Live site: https://iamhanzla.vercel.app/ (connect this repo in Vercel)
Repo owner: github.com/hanzlikhan

## How to update it yourself (no coding tool needed)
1. Go to this repo on github.com > open `index.html`
2. Click the ✏️ pencil icon > Edit
3. Change only the text you want (name, project, skill, link)
4. Click **Commit changes** — Vercel will auto-deploy in ~1 minute.

## How to edit on your computer (recommended for big changes)
```bash
git clone https://github.com/hanzlikhan/muhammad-hanzla-portfolio.git
cd muhammad-hanzla-portfolio
# edit index.html in VS Code, then:
git add .
git commit -m "Update portfolio"
git push
```

## Files
- `index.html` — the whole site (hero, skills, projects, Dietora simulator, timeline, contact)
- `.gitignore` — ignores system files

## What to change over time
- New project? Copy one project card block in `index.html` and change title/tech/bullets.
- New achievement? Add one item in the timeline section.
- New job / CGPA / contact? Search in `index.html` for the old text and replace it.

Do NOT rename index.html — Vercel / GitHub Pages need that exact name.
